# docs/archive

## Estatus

Este directorio contiene **material histórico**. No es canónico, no es vinculante para decisiones actuales, y no se indexa en el Source of Truth como autoridad.

## Precedencia

Según [ADR-001 §1](../decisions/ADR-001-document-authority-and-layout.md), `docs/archive/` tiene **precedencia 7** (la más baja del sistema). Si existe contradicción con cualquier documento de mayor precedencia, prevalece el documento de mayor precedencia.

## Política de curación

El contenido de este directorio **solo puede curarse o moverse mediante una TASK documental explícita** con ownership keys que incluyan las rutas afectadas. No se realizan cambios ad hoc ni por convención tácica.
